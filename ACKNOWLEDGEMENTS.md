## Acknowledgements

Amberlog is an independently implemented open-source project, released under the Apache License 2.0. It would not exist without the projects below.

### Open-source projects Amberlog is built on

Amberlog is built directly on these open-source projects:

| Project | Use in Amberlog |
|---|---|
| [Apache Arrow](https://arrow.apache.org/) (Rust implementation) | In-memory columnar data format |
| [Apache DataFusion](https://datafusion.apache.org/) | SQL engine for search |
| [Apache Parquet](https://parquet.apache.org/) (Rust implementation) | Columnar file format stored in object storage |
| [Apache Iceberg](https://iceberg.apache.org/) ([iceberg-rust](https://github.com/apache/iceberg-rust)) | Open table format of the cold tier |
| [object_store](https://crates.io/crates/object_store) | Access to object storage |
| [pg_query](https://crates.io/crates/pg_query) (embeds the PostgreSQL SQL parser) | Parsing search statements |
| [Tokio](https://tokio.rs/), [axum](https://github.com/tokio-rs/axum), [rustls](https://github.com/rustls/rustls) | Async runtime, HTTP server, TLS |

For the full list of third-party dependencies and their licenses, see the third-party notices shipped with the prebuilt binaries and container images. They are generated by `tools/third-party-notices.sh`.

### Projects that informed the design

Amberlog's design draws on the published designs and documentation of the three projects below. Amberlog is an independent implementation.

- [OpenObserve](https://github.com/openobserve/openobserve)
- [VictoriaLogs](https://github.com/VictoriaMetrics/VictoriaLogs)
- [GreptimeDB](https://github.com/GreptimeTeam/greptimedb)

We thank these projects for making their designs and documentation public.

### 致谢

Amberlog 是独立实现的开源项目，按 Apache License 2.0 发布。没有下面这些项目，就没有 Amberlog。

#### 构建所依赖的开源项目

Amberlog 直接构建在这些开源项目之上：

| 项目 | 在 Amberlog 里的用途 |
|---|---|
| [Apache Arrow](https://arrow.apache.org/)（Rust 实现） | 内存中的列式数据格式 |
| [Apache DataFusion](https://datafusion.apache.org/) | SQL 检索引擎 |
| [Apache Parquet](https://parquet.apache.org/)（Rust 实现） | 存储在对象存储里的列式文件格式 |
| [Apache Iceberg](https://iceberg.apache.org/)（[iceberg-rust](https://github.com/apache/iceberg-rust)） | 冷层的开放表格式 |
| [object_store](https://crates.io/crates/object_store) | 访问对象存储 |
| [pg_query](https://crates.io/crates/pg_query)（内嵌 PostgreSQL 的 SQL 解析器） | 解析检索语句 |
| [Tokio](https://tokio.rs/)、[axum](https://github.com/tokio-rs/axum)、[rustls](https://github.com/rustls/rustls) | 异步运行时、HTTP 服务、TLS |

完整的第三方依赖及其许可，见预编译二进制和容器镜像附带的第三方许可声明。生成办法见 `tools/third-party-notices.sh`。
