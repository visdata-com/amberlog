# 控制台开发约定

视觉与组件说明见 [界面规范](ui-guidelines.md)。

## 范围与复用

围绕完整目标提交公共样式、控件和调用页面，让每个提交能独立构建和展示。
保留接口字段、查询语义、时间精度、取消、分页与错误处理的既有约定，保留已有需求编号。
优先复用 `components/ui/` 和 `shell/` 的组件，原生属性、事件、ref 和标签由调用方保留。
页面样式限制在对应屏幕内。复选框、文本框、下拉和表格滚动分别处理，避免全局覆盖影响其他控件。
弹层处理关闭、焦点和可视区域边界，不能依赖悬停作为唯一操作方式。

## 时间与业务边界

UTC 微秒和时区转换复用 `TimeRange` 与 `lib/time.ts`，不使用浏览器时区替代用户选择。
三屏范围分别保存；编辑控件不擅自执行查询。台账和对账保留中性判定，不将当前返回上限内的记录称为全量汇总。

## 验证与提交

运行类型检查、前端单测、构建、嵌入资源一致性和依赖许可检查。
涉及交互时验证相应浏览器流程，并同步调整 Rust 浏览器用例。
检查三屏及浅色、深色、窄屏，尤其是下拉、抽屉、长表和空结果。
构建资源随源码提交；有冲突时先合并源码再构建，不手工合并哈希资源。
全量 Rust 验证以 `CONTRIBUTING.md` 为准，如实记录已完成和待补检查。
