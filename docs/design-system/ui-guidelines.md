# 控制台界面规范

适用于检索、台账、对账页面。界面不依赖外部字体、图标服务或运行时资源。

## 主题与尺寸

公共变量定义在 `ui/src/style.css`，浅色、深色和跟随系统通过顶部外观选择器切换。
颜色使用 `--bg`、`--panel`、`--text`、`--muted`、`--line`、`--button`、`--link` 等公共变量。
字号、间距、圆角和阴影复用 `--font-size-*`、`--space-*`、`--radius*`、`--shadow-*`。
标准输入框和按钮使用 `--control-height`。正文使用本机中文无衬线字体，时间和 SQL 使用等宽字体。
错误和提示有明确文字；台账、对账继续以中性文字和数值呈现判定。

## 公共组件

| 组件 | 职责 |
|---|---|
| `components/ui/Button.tsx` | 主、次操作样式；默认 type 为 button，调用方决定禁用和点击行为 |
| `components/ui/Input.tsx` | 普通和嵌入输入，透传原生属性与 ref |
| `components/ui/Checkbox.tsx` | 保留原生勾选行为和标签，不套用文本框尺寸 |
| `shell/Select.tsx` | 主题、时区和快捷范围共用下拉，时区支持搜索 |
| `shell/DatasetInput.tsx` | 检索和对账共用的手动输入与候选选择 |
| `shell/ResultArea.tsx`、`ResultState.tsx` | 初始、加载、空结果及错误反馈 |
| `shell/TableScroll.tsx` | 表格内部滚动，新结果回到顶部，普通更新保留位置 |

## 布局与交互

顶部导航保留时区、外观和口令，窄屏允许换行。检索的模式、数据集、时间、查询和历史位于同一查询面板。
字段栏与结果区并排，窄屏上下排列；长字段和值不撑破页面。
分布图显示时间轴、范围和分桶说明，支持提示、点击、拖选和键盘操作。
详情以抽屉和遮罩呈现，打开时移入焦点，Tab 留在抽屉内，关闭后恢复焦点。
台账、对账使用剩余页面高度，宽表在结果区域内滚动。
保留已有路由、404、跨屏跳转、查询历史和各屏草稿。

## 验收

检查三屏的浅色、深色和窄屏，以及初始、加载、空结果、失败和有数据状态。
控件与调用页面同步调整，相关浏览器测试随功能提交，构建资源与源码一起提交。

## 检索时间范围选择器

检索页使用 `shell/TimeRangePicker.tsx`；台账和对账继续使用原有的起止输入和快捷范围。
相对模式提供快捷项，范围以查询发出时刻计算。绝对模式用日历选起止日期，时间支持分钟、秒及最多六位小数。
摘要和预览显示到秒，未编辑端点保留原有微秒和 UTC 时刻。范围按顶部所选时区解释，沿用夏令时转换规则。
选择只更新范围，不发查询；无效或不完整范围有明确说明，查询时仍按既有规则拒绝。
弹层支持键盘、Escape 和点击外部关闭；切屏、外部范围或时区变更时关闭旧草稿。

## 条件输入与提交

输入框按字段、运算符和值提供候选；完整条件可回车加入，也可直接点击查询提交。
切换 SQL 时先处理输入草稿，避免遗漏条件。查询成功发起后清空输入，同一个草稿只加入一次。
不完整字段条件和未闭合引号显示明确错误，保留用户输入，不发请求或切换 SQL。
空输入不显示无意义候选；中文输入法组合输入期间的回车不提交条件。
